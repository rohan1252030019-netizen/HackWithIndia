## 🏛️ About

HackWithIndia (HWI) is a nationwide innovation community connecting **50,000+ student developers** across India. The **VIT Pune Student Chapter** operates as a year-round ecosystem — not just an annual event — connecting VIT Pune students with:

- 🏆 **National hackathons** with ₹10L+ bounties
- 🧠 **Industry mentors** from Microsoft, GitHub, Postman, Polygon & more
- 💻 **Deep-dive masterclasses** on AI, Web3, Cloud, and Open Source
- 🚀 **Direct industry referrals** and internship pipelines

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/rohan1252030019-netizen/HackWithIndia.git
cd HackWithIndia

# Install dependencies
npm install

# Start development server
npm run dev
# → http://localhost:5173

# Production build
npm run build
```
